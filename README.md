# CardioSense ❤️

CardioSense is a heart disease prediction web application that uses a machine learning model to generate predictions from user-provided health parameters.

### Tech Stack
- **Frontend:** Next.js, React, TypeScript
- **Backend:** Python, FastAPI
- **ML:** Scikit-learn, Pandas

### Features
- Health parameter input form
- ML-based predictions
- Responsive web interface
- REST API integration

### Run Locally

**Frontend**
```bash
cd frontend
npm install
npm run dev
```

**Backend**
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
