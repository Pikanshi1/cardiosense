# ❤️ Heart Stroke Prediction

A simple **Machine Learning + Streamlit** project that predicts the risk of heart disease based on user-provided health parameters.

## 🛠️ Tech Stack

* Python
* Pandas
* Scikit-learn
* KNN
* Joblib
* Streamlit

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📌 Features

* Interactive Streamlit interface
* KNN-based prediction
* Input scaling using a saved scaler
* Simple risk prediction

> ⚠️ This project is for educational purposes only and should not be used as medical advice.
